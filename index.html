AIS-407: Qwen3.8-27B as the agent; a Jev step flagger holds suspicious actions for an inline auditor (DeepSeek V4.1 Flash), which questions the agent and then blocks or allows the action. Auditor 1 is black-box, auditor 2 adds a deception probe's reading of each yes/no answer, auditor 3 also sees the agent's system prompt and reasoning.

Pilot result: without an auditor the side task succeeded in 10/10 attack runs; with each auditor in 0/10. Honest runs blocked: 1/10, 3/10 and 1/10.
